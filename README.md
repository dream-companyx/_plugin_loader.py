# 🧩 Плагины DreamyLauncherMega

Папка для плагинов лаунчера **DreamyLauncherMega**.

Плагины — это `.py`-файлы, которые добавляют лаунчеру новые возможности:
версии Minecraft, интеграции с сервисами, автоматизацию, кастомные события.

---

## ⚠️ ВАЖНО: Безопасность

**Плагины — это сторонний Python-код.** Они выполняются **внутри лаунчера** 
и имеют **полный доступ** к:

- 📁 файловой системе (могут читать/удалять/изменять любые файлы)
- 🌐 интернету (могут отправлять данные куда угодно)
- 🖥 системе (могут запускать любые программы через `subprocess`)
- 🔑 вашим аккаунтам (могут украсть токены Ely.by, пароли, UUID)
- 💾 памяти лаунчера (могут получить доступ ко всему, что там хранится)

**Что может сделать вредоносный плагин:**

| Угроза | Как выглядит |
|---|---|
| 🔴 Кража аккаунтов | Сливает `accounts.db` или расшифрованные пароли на свой сервер |
| 🔴 Шифровальщик | Зашифрует ваши файлы и потребует выкуп |
| 🔴 Майнер | Тихо майнит криптовалюту в фоне |
| 🔴 Бэкдор | Открывает удалённый доступ к вашему ПК |
| 🔴 Поломка лаунчера | Удаляет `secret.key`, ломает `accounts.db`, вешает окно |

**ПРАВИЛА БЕЗОПАСНОСТИ:**

1. ✅ Ставьте плагины **только из проверенных источников**.
2. ✅ **Прочитайте код плагина** перед запуском — это `.py`-файл, его можно открыть в блокноте.
3. ✅ Если видите **обфускацию** (непонятные символы, `exec()`, `eval()`, base64) — **не запускайте**.
4. ✅ Держите **резервную копию** `accounts.db`, `secret.key`, `.minecraft/`.
5. ❌ **Никогда** не ставьте плагины "для теста" от незнакомых людей.

## 📂 Как это работает
DreamyLauncherMega/
├── DreamyLauncherMega.pyw ← главный файл лаунчера
└── plugins/ ← ЭТА ПАПКА
├── _plugin_loader.py ← 🧠 BRIDGE (обязателен!)
├── .enabled.json ← какие плагины включены
├── .acknowledged ← флаг "принял риск"
├── README.md ← этот файл
├── _example_simple.py ← пример: только версии
├── _example_events.py ← пример: только события
└── my_plugin.py ← ваш плагин (любое имя, кроме _*)

text

**BRIDGE** (`_plugin_loader.py`) — **обязателен**. Без него:

- ❌ Лаунчер **не покажет** вкладку «🧩 Плагины».
- ❌ Версии из плагинов **не появятся** в комбобоксе.
- ❌ Ни один плагин **не будет загружен**.
- ❌ События **не будут вызваны**.

**Bridge — единственный файл, которому доверяет лаунчер.** Он сам решает, 
какие `.py` в папке являются плагинами, и предоставляет им API.

## 🚀 Быстрый старт

### 1. Установите bridge

Положите `_plugin_loader.py` в папку `plugins/`.

Или нажмите **«📥 Скачать загрузчик»** в лаунчере (Настройки → Плагины).

### 2. Создайте свой плагин

Файл `plugins/my_plugin.py`:

```python
# Метаданные (обязательны для отображения)
PLUGIN_NAME = "My Plugin"
PLUGIN_AUTHOR = "Your Name"
PLUGIN_VERSION = "1.0.0"
PLUGIN_DESCRIPTION = "Что делает плагин"

def get_versions():
    """Список версий, которые умеет ставить плагин."""
    return [
        {
            "id": "my-version-1",
            "type": "vanilla",       # vanilla / forge / neoforge / fabric
            "name": "My Version 1",  # как показывать в комбобоксе
        },
    ]

def install_version(version_id, ctx):
    """Установить версию. ctx — PluginContext."""
    ctx.log(f"Ставлю {version_id}")
    ctx.progress(0, "Начинаю")
    # ... ваш код скачивания ...
    ctx.progress(100, "Готово")
    return True
